
# Tushonka: Most Wanted

**Every target has a price.**

Tushonka: Most Wanted introduces a new bounty-hunting experience to SPT, featuring a custom trader, repeatable contracts, configurable rewards, and an extensive black-market arsenal.

## Meet Handler

A former military intelligence officer with connections to underground arms dealers and private military networks, Handler specializes in locating high-value targets and supplying mercenaries with the equipment necessary to eliminate them.

He doesn't care how you get the job done. He only cares about results.

## Features

### Bounty Hunting

- Repeatable bounty contracts.
- A variety of targets and contract objectives.
- New contracts generated after completion.
- Configurable bounty difficulty and rewards.
- GP coins, currency, and equipment rewards.

### Black Market

- An extensive selection of weapons and tactical equipment.
- Custom, practical weapon builds.
- Fully equipped armor with compatible ballistic plates and soft armor.
- Premium ammunition, optics, suppressors, and magazines.
- Medical supplies, stimulants, helmets, and storage cases.
- Purchases using roubles and GP coins.

### Trader Progression

- Four trader loyalty levels.
- Progressively unlocked weapons and equipment.
- Exclusive high-end equipment for experienced bounty hunters.
- Balanced pricing and equipment availability.

### Customization

The mod includes configurable settings, allowing players to tailor their bounty-hunting experience.

Configuration files are automatically generated on the first server launch.

| File | Description |
| --- | --- |
| `config.json` | General mod and bounty settings |
| `rewards.json` | Customizable reward pools |

## Requirements

- SPT 4.1.x
- Compatible versions will be specified with each release.

## Installation

1. Download the latest compatible release.
2. Extract the downloaded archive.
3. Place the mod folder inside `SPT/user/mods/`.
4. Launch the SPT server.
5. Start the game and locate Handler in the trader menu.
